# 🗣️ Natural Language Processing: Political Speech Mining

[![Python](https://img.shields.io/badge/Python-spaCy-09A3D5.svg?logo=spacy&logoColor=white)](https://spacy.io/)
[![NLTK](https://img.shields.io/badge/NLTK-NLP-388E3C.svg)](https://www.nltk.org/)

An NLP exploration pipeline analyzing French political speech corpora using tokenization, statistical term frequency indexing, and linguistic processing with modern libraries.

---

## 🛠️ Notebooks Overview

1. **`01_tokenization_frequency_wordcloud.ipynb`**:
   - Text ingestion, character normalization, custom tokenizers, and term-frequency index building.
   - Stop-word filtering, lexical diversity measurements, and visualization via `WordCloud`.
2. **`02_spacy_linguistic_processing.ipynb`**:
   - Advanced linguistic pipeline powered by the French spaCy model (`fr_core_news_md`).
   - Part-of-speech (POS) tagging, lemmatization, and named entity recognition (NER).
