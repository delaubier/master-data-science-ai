# 🌐 Web Scraping & Distributed Processing

[![Python](https://img.shields.io/badge/Python-BeautifulSoup-3776AB.svg)](https://www.crummy.com/software/BeautifulSoup/)
[![R](https://img.shields.io/badge/R-rvest-276DC3.svg)](https://rvest.tidyverse.org/)

Web scraping pipelines developed in both Python and R, highlighting HTML parsing, User-Agent rotation, and multi-process distributed requests.

---

## 🛠️ Modules

- `multiprocessing_scraper.py`: Asynchronous and parallel extraction using Python's `multiprocessing.Pool` with `BeautifulSoup` and `lxml` parsers.
- `rvest_wikipedia_scraper.R`: Clean R tidyverse web scraping workflow using `rvest`, CSS selectors, and XPath extraction.
