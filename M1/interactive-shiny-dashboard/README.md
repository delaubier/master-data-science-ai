# 📈 Interactive R Shiny Application

[![R](https://img.shields.io/badge/R-Shiny-276DC3.svg?logo=r&logoColor=white)](https://shiny.posit.co/)

A reactive web dashboard developed in R Shiny demonstrating dynamic data binding, user input reactive graphs, and parameter customization.

---

## 🚀 Features

- **Reactive Histogram Engine:** User-controlled binning, dynamic palette selection via `colourpicker`, and live class frequency counting.
- **Modular Architecture:** Clean decoupling between frontend layout (`ui.R`) and server backend execution (`server.R`).

## 💻 Running the App
```r
library(shiny)
runApp(".")
```
