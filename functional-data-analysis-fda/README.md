# 📉 Functional Data Analysis (FDA) & Continuous Signal Modeling

[![R](https://img.shields.io/badge/R-fda-276DC3.svg?logo=r&logoColor=white)](https://cran.r-project.org/web/packages/fda/index.html)
[![Advanced Statistics](https://img.shields.io/badge/Domain-Functional%20Data-purple.svg)]()

Functional Data Analysis (FDA) focuses on the statistical modeling of curves, continuous signals, and image/spectral profiles where individual observations are functions defined over a continuum (time, frequency, space).

---

## 🔬 Topics Covered

1. **`01_canadian_weather_fda.Rmd`**:
   - Representation of continuous climate profiles (daily temperature records across Canadian weather stations).
   - Smoothing discrete daily measurements into infinite-dimensional functional objects.
2. **`02_fourier_basis_expansion.Rmd`**:
   - Expansion of signals onto orthogonal Fourier and B-spline functional bases.
   - Basis evaluation matrices, roughness penalties, and functional PCA.
